# AI Agent Operations Manual

This repository is maintained by AI Agents and human engineers.
All AI Agents MUST adhere to the following rules unconditionally.

1. Read `.agents/quality.md` before making any code modifications to understand project-specific quality gates.
2. Read `.agents/patterns.md` to ensure code aligns with approved architectural patterns and Git standards (Conventional Commits, Atomic Commits).
3. Read the relevant package context in `.agents/context/{package}.md` before modifying any specific module.
4. Review existing skills in `.agents/skills/` (e.g., `git-workflow`) to reuse known AI workflows.
5. Create new skills or update existing context files if you establish new patterns or rules.
6. The `GEMINI.md` files located in package roots act as localized instructional context for the Gemini CLI and override global defaults.
